
# My Final Year Project

My official Final Year Project (FYP) title is "Exam Integrity System".

The project focuses on AI-assisted decision support for physical examination hall management.

Its main purpose is to identify potential conflicts in student seating arrangements, such as hall overcapacity, duplicate roll number allocation, and hall unavailability.

The system considers uncertainty in available information and sends unclear cases to a human reviewer, such as an admin or invigilator.

The proposed solution is a software-based web prototype with a student allocation interface and a teacher or admin dashboard.
